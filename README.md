# 🎵 Music Album UI

A modern and responsive **Music Album Landing Page** built using **HTML5** and **CSS3**. This project showcases an interactive album interface with animated track cards, audio playback, and a visually appealing user experience.

## 🚀 Live Demo

🔗 **View Project:** https://music-enter.netlify.app

---

## 📌 Features

- 🎨 Modern and responsive UI
- 🎵 Interactive music track selection
- ▶️ Built-in HTML5 audio player
- ✨ Smooth CSS animations and transitions
- 💿 Album cover section
- 🎼 Track list with hover effects
- 👨‍🎤 Artist information section
- 📱 Responsive layout using Flexbox

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- HTML5 Audio
- Flexbox
- CSS Animations
- CSS Gradients
